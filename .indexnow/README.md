IndexNow submits only HTTPS URLs on the host listed in sites.json after the matching production revision is live. Keys are public ownership verification files, not account tokens. No Bing or Vercel credential is needed. New and changed pages are detected by content hashes in state.json and the GitHub Actions cache. Each run checks robots.txt, noindex, canonical links, HTTP status and the public key file. HTTP 200 means accepted, 202 means key validation pending; neither confirms indexing. Reports are saved as Actions artifacts. If the cache expires, eligible URLs may be submitted again. Manual run: python3 .indexnow/notifier.py --submit. Primary setup: 2026-10-21.
